# Shared wallpaper assets / 共享壁纸素材

The independent Stillwall prototype retired on 15 November 2026. Its old HTML URLs now lead to the [current Browse wallpaper site](../browse/wallpaper.html?lang=en&v=audio1); the old Cornhub URLs lead to the current advertiser page.

`catalog.js` and the eight original illustrations in `assets/*.svg` remain here because Browse uses them. Their paths and contents are unchanged. Personal wallpaper use is permitted. Browse adds further sourced photographs and credits in its own catalogue.

独立壁纸站已停用。当前 Browse 里的 Stillwall 场景继续保留；这两者不是同一套运行代码。本目录只保留当前网站需要的目录、八张原创 SVG 和旧网址跳转。原独立站的代码与素材副本已在本机归档，不再作为可单独托管的网站发布。
