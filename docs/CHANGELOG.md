# Release history / 版本记录

Current version: **[events1a](https://github.com/gary1110086/CSpopups/releases/tag/v-events1a)**. [中文功能概览](../README.zh-CN.md#随机事件) · [Detailed verification](../browse/VERIFICATION.md).

## events1a — 25 October 2026

- Added eight action-driven encounters: sponsor chat, original-tab title reminders, inline-to-floating video, genuine search shortcuts with a sponsored link, escalating offers after refusals, an animated visitor, quiet/comeback messages, and optional bonus ads after an actual save, export or completion.
- Each seed selects three applicable event types. A type appears when its browsing action occurs; the image tool and rail planner omit text-search suggestions. Seen events stay consumed through reload and Back.
- Kept dense stacked ads, evasion throughout the viewport with a limit of 4–6 actual evasions, ten-second hidden-close disclosure, varied close corners and selected-session collisions. New widgets retain genuine closes; Escape and modal controls apply to them too.
- Preserved real media playback/seeking, local image processing and exports, native advertiser tabs and the original task workspace. Scheduling and media pause outside active foreground browsing; manual video pause remains respected.
- Fixed false completion signals when removing a saved recipe/outing, undoing book-reading completion or removing an artwork from comparison. These undo actions no longer trigger bonus ads.
- Grouped the earlier article-site runtime under `prototypes/little-daily/`, kept its public HTML routes available, and added this documentation index, release record and downloadable package.

本版新增八种随机事件，每次选取三种适用类型，并保留原有弹窗机制。取消收藏、撤销阅读完成和移出作品对比不会再误触发奖励广告。当前浏览体验仍从 `browse/launch.html` 进入；根网址和早期网页入口继续保留。
