# 60秒任务挑战 / One Minute

活动版入口把选题、读题、真实网站、60秒倒计时、本轮结果和复盘连在同一个原生浏览器标签页里。

- [纯净难度测试 / Clean test](https://gary1110086.github.io/CSpopups/browse/clean.html?lang=zh&v=minute1)
- [广告挑战 / Ad challenge](https://gary1110086.github.io/CSpopups/browse/booth.html?mode=ads&lang=zh&v=minute1)
- [English clean test](https://gary1110086.github.io/CSpopups/browse/clean.html?lang=en&v=minute1)

## 工作人员怎么用

1. 先在纯净入口选一题或随机抽题。纯净模式不初始化广告、声音、Cookie干扰和误导开关，也移除网站自带的赞助推荐。
2. 让参与者读完题目及完成条件，再点击开始。读题期间不计时。
3. 网站首次可操作后开始60秒。浏览、搜索、详情、刷新、返回以及广告标签页消耗的时间都算在同一轮中。顶部有“查看任务”和“我完成了”。
4. 到时自动在原任务标签页显示结束页；也可提前交卷。若参与者正在广告标签页，工作人员提示返回原任务页。浏览器后台调度可能延迟画面切换，恢复后按原截止时间立即结束，不补时间。
5. 结果页给出截止前记录到的收藏/参数/导出证据。工作人员核对后选择已完成、部分完成或未完成，再进入对应seed的本轮复盘。机器证据不是阅读理解或文件落盘证明。
6. 关闭上一轮广告标签，在交接区确认后点击下一位。新一轮生成新seed，收藏与任务状态独立；不会清空整个标签页的旧记录。

来源、图片署名与其他辅助说明会另开原生标签，原任务页的60秒继续计时。

网站内的工作人员按钮可以因加载/设备问题作废本轮。作废单独标记。查看任务或进入其他标签不会暂停挑战；Escape处理广告，不能重开60秒。

## 导出与结果的边界

导出条件要求在截止前成功生成文件，并发起下载请求。仅点击按钮、编码仍未完成，不算完成；到时不额外延长，异步回调不得补记。工作人员可检查实际下载文件。取消收藏或改错份量会撤销相应机器条件；提前交卷本身不代表答对。

本轮观察保留在当前标签页的sessionStorage中，不跨电脑同步。结果/复盘可分别导出TXT。轮次索引最多保留12轮；旧的广告观察记录沿用其独立数量上限。

## 本地运行

```sh
python browse/preview-server.py --port 5210
```

打开 `http://127.0.0.1:5210/browse/clean.html?lang=zh&v=minute1`。需从仓库根目录提供共享的assets与wallpapers资源。

GitHub Release中的cleaner1 ZIP是此前的版本，不包含minute1活动入口。需要活动版时使用上方在线入口或当前仓库源码。

普通Browse自由浏览、早期Little Daily和独立Stillwall继续使用各自原来的流程；它们不会因为活动版新增而自动限时。
