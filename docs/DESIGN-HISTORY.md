# 早期设计整理

现在只维护「一分钟挑战」和它使用的 Browse 网站、广告目的地。以下四条旧路线于 2026 年 11 月 15 日停用，源码和旧 ZIP 留作本机归档。

| 设计 | 当时想做什么 | 现在怎么处理 |
| --- | --- | --- |
| Little Daily / Just One Minute 文章站 | 从仿连接检查页进入文章，阅读时遇到广告和 Cornhub 跳转。 | 停用。根网址和文章旧链接进入当前一分钟挑战。 |
| 初代模拟浏览器游戏 | 在网页里模拟标签栏、地址栏和回合操作。 | 停用。本地源码归档，不放回当前入口。 |
| 找不同原型 | 较早的独立展台玩法。 | 停用。旧脚本、样式和启动文件归档。 |
| 独立 Stillwall 壁纸站 | 单独运行的八张插画壁纸站，带下载和定时广告。 | 停用独立运行代码。旧网址进入 Browse 壁纸场景；共用目录和 SVG 保留。 |

当前保留的设计包括：十三道一分钟任务、十二个可操作的网站、各自的搜索/收藏/比较/导出，以及广告目的地和干扰机制。Browse 里的 Stillwall 和 Cornhub 继续使用，不能因为旧原型同名就一起删除。

`wallpapers/catalog.js`、八张 `wallpapers/assets/*.svg`、共享图标和 `assets/nightroom-contact-sheet.png` 仍被当前网站引用，路径不变。早期生成图与现实照片的来源记录也保留。

本机原稿在 `local/retired/2026-11-15/`，附 SHA256 清单；历史 ZIP 在 `archives/releases/`。这些目录不上传 GitHub。旧网页已被浏览器缓存时，可能仍显示旧内容；刷新后的服务器版本只提供兼容跳转。

GitHub 历史提交仍能查到旧源码，历史 Release 仍可下载旧快照。这次停用没有重写 Git 历史或改动旧 ZIP。
