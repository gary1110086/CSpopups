# Official open-film catalogue stills

Retrieved on23October2026 from public Blender Studio project pages. The public movie list uses poster art; the delivered images instead use project OG stills without logos. Charge uses the public thumbnail of shot050_0130. No subscriber file, studio screenshot or film trademark logo was copied.

Blender Studio’s [remixing policy](https://studio.blender.org/remixing/) declares its content generally CC BY with copyright Blender Foundation. The project licensing pages forWingIt! andCoffeeRun explicitly specifyCCBY4.0; GlassHalf explicitly specifiesCCBY3.0. Other records retain the policy’s unversionedCCBY wording rather than guessing a version.

All stills are re-encoded JPEGs at native size or at most640pixels wide. CSS crops them into catalogue covers and adds original text overlays. Source composition is retained in the delivered landscape file.
