## 中文使用说明

本版提供十个可检索、可操作的日常网站与30项具体任务。网站内的顶部任务说明及笔记栏暂不显示，任务可在独立任务库查看。建议活动人员先打开任务库，给参与者一个明确目标，再让其自行检索、核对详情、收藏或导出。广告过程中打开真实标签，参与者可关闭广告标签并回到原任务。没有显示计时器，不会自动结束。

弹窗有六种：普通角落卡、模态推广、小关闭键卡、可带拒绝选项的推广、屏幕内反弹卡和鼠标接近 × 时整卡躲避的卡片。首次约3秒前台专注时间后出现，随后每2.2–3.2秒补入，电脑最多同时4张、640px及以下最多2张，普通广告保留30次独立预算，另加一次手动爆发，合计不超过40张不同广告。关闭一张保留其他卡，补位至少等0.8秒；另有顶部促销条、底部横幅、宽屏侧栏与正文赞助区。环境广告单独关闭后隐藏10秒；Esc清除全部广告并提供5秒前台专注时间空档。

闪避覆盖全屏可用位置，边缘取样概率更高，每卡随机闪避4–6次后不再跑，刷新及原生前进后退会保留次数。关闭样式独立随机排列：普通明显×、明显×加外侧透明×、仅外侧透明×；外侧按钮随布局位于右上、左上或右下方约26–27px，键盘聚焦时清晰显示。仅透明×的卡片在出现10秒前台专注时间后，×自动变为白底、深色边框的明显按钮，该卡片停止反弹或闪避，保证可点击；每张独立计时，后台暂停，刷新及前进后退保留等待进度。内部滚动与30px顶部／底部预留避免裁掉关闭键。键盘聚焦暂停移动，触屏不躲避，减少动态效果时保持静止；这些操作不消耗闪避次数。节奏使用br-run-v8，缺少记录才顺序导入v7/v6/v5/v4/v3/v2/v1，原br-data-v1场景数据与笔记保留。

广告会结合场景与搜索词，一个本地赞助商沿页面访问推进三阶段文案；赞助推荐放在列表中途或实际阅读路径，广告页面内可继续游戏、转盘和比较优惠。普通会话有30%概率启用碰撞，开发者爆发必定启用；静止浮窗也会被推开，以300ms平滑位移及短暂压缩呈现挤压。键盘聚焦、鼠标按住、模态框、减少动态效果及已显露的关闭键仍暂停相应动作；纯触屏设备保持静止有界布局。十张布局牌组中右下关闭占一张，右上假×配左上真关闭占一张，其余保留常规与左上角变体；假×打开广告并保留原卡。

两位工作人员可分别负责说明任务与观察操作，以及在另一台设备查看主持人答案和资料、引导结束讨论。不要替参与者点击；观察他如何筛选、核对、识别误导控件，以及是否能恢复原来的工作。
