# AdSweep product destination: references and adaptation

AdSweep is an original, fictional cleaner/advertising-control brand in the CSpopups educational browsing exercise. It is not AdBlock, a browser vendor, an extension store, or a computer-security provider. The page has no executable download, real extension installation, account, payment form, external tracking or browser permission request.

## Original content and interaction

- All interface markup, CSS illustrations, copy, product name and logo mark were authored for this project. The reading-page illustration is a local sample, not a real publisher screenshot or counterfeit browser interface.
- The sample has eight real DOM promotional elements in four categories. The check reviews those predefined sample categories; it is not an operating-system, malware, extension or original-tab scan. No measurement of the user’s other tabs is claimed.
- Native routes cover overview, sample scan, report, Basic/Plus comparison, local settings and completion. `lang`, `seed`, `v`, `from` and `task` remain in navigation; a genuine return link leads back to the original scene.
- Settings affect only the AdSweep sample. They do not clear the original site’s ads. The comparison and downloadable TXT settings export are functional.
- One independently dismissible Plus promotion deliberately appears on this page. It illustrates how a “fewer ads” promise can itself introduce another advertisement. Its close button closes the offer without advertising, and Escape also dismisses it.
- Local state uses `br-data-v1:<seed>:cleaner-v1` in this tab’s session storage. The completed sample check, chosen preview settings and dismissed promotion remain local. There is no network submission.
- Fictional annual example: RM 3.90/month, billed RM 46.80/year. Fictional monthly example: RM 6.00/month. Plan and setup screens disclose these terms and that no real charge/subscription occurs.

## Boundaries

References were used for commercial page conventions and documented persuasion mechanisms, not to imply that the referenced providers engage in the exercise’s deceptive behaviour. External source pages are documentation only; the runtime has no third-party media dependency.
